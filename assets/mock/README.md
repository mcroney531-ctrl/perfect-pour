# Mock assets

Exported straight from the running game (glass A, the default), so they match
the live asset exactly. SVG for editing or scaling; PNG at 4x with a
transparent background.

| File | State |
|---|---|
| `glass-a-empty` | Upright, empty |
| `glass-a-tilted-pouring` | Tilted ~45°, about 40% full (stream removed) |
| `glass-a-full` | Upright at the line with a ~12% head, no training marks (what Solo looks like) |
| `glass-a-full-training-bands` | Same, with the BRING UP band and LINE zone (Watch/Guided) |
| `glass-a-preview-dark-light.png` | All four on dark and light backgrounds |

Glass A is light glass drawn for a dark scene: on a light background its
outline almost disappears. Mocks on light backgrounds need a darker-outline
variant.
